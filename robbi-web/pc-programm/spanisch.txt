#
# FORMAT:   spanisch ; deutsch ; optionale Notiz
# Neue Kategorie einfach mit [Name] beginnen. Zeilen mit # werden ignoriert.
# Grundlage ist Spanisch aus Spanien; wo Lateinamerika anders sagt, steht es als Notiz.
#
# AUSSPRACHE (Spanisch spricht man fast so, wie man es schreibt):
#   c vor e/i, z = in Spanien wie engl. "th" (gracias), in Lateinamerika wie s
#   c sonst    = k (casa)            ch = tsch (chico = tschiko)
#   j, g vor e/i = ch wie in "Bach" (jamón = chamón, gente = chente)
#   gue/gui    = ge/gi, das u ist stumm (guitarra = gitarra)
#   ll         = j wie in "ja" (calle = kaje)      ñ = nj (mañana = manjana)
#   qu         = k (queso = keso)                   h = stumm (hola = ola)
#   v          = fast wie b (vino = bino)           y = j (yo = jo), allein "y" = i
#   r          = kurz gerollt, rr = lang gerollt (pero ≠ perro)
#   Akzent (á é í ó ú) = diese Silbe betonen
#   ¿...? und ¡...! stehen auch am Satzanfang
#   Bei Verben steht vorne: Infinitiv – ich-Form
