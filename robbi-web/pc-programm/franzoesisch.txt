#
# FORMAT:   französisch ; deutsch ; optionale Notiz
# Neue Kategorie einfach mit [Name] beginnen. Zeilen mit # werden ignoriert.

# AUSSPRACHE (Französisch schreibt man anders, als man es spricht):
#   Endungen meist stumm:  -e, -s, -t, -d, -x, -z (petit = peti, temps = tang)
#   -er / -ez / -é  = e (parler = parle, chez = sche)       -et = ä
#   ou  = u (vous = wu)          u  = ü (tu = tü)           oi = oa (moi = moa)
#   au / eau = o (beau = bo)     ai / è / ê = ä (mais = mä)  eu = ö (deux = dö)
#   an / en = nasales "ang", on = "ong", in / ain / un = nasales "äng" (das g kaum hörbar)
#   ch  = sch (chat = scha)      j / g vor e,i = weiches sch wie in "Journal"
#   gn  = nj (montagne)          qu = k        ç / c vor e,i = s       h = stumm
#   ille = ij (fille = fij)      v = w (vin = wäng)         z / s zwischen Vokalen = weiches s
#   Umgangssprache: "ne" fällt oft weg (je sais pas statt je ne sais pas), "on" statt "nous"
#   Bei Verben steht vorne: Infinitiv – ich-Form
