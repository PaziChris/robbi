# AUSSPRACHE (Serbisch spricht man genau so, wie man es schreibt – jeder Buchstabe ein Laut):
#   c  = z wie in "Zeit" (cena = zena)          č  = tsch, hart (čaj = tschai)
#   ć  = tsch, weich (kuća = kutscha)           dž = dsch, hart (džep)     đ = dsch, weich (đak)
#   š  = sch (šta = schta)                      ž  = weiches sch wie in "Journal" (žena)
#   j  = j wie in "ja"                          lj = lj wie in "Million" (ljubav)
#   nj = nj wie in "Champagner" (konj)          h  = ch wie in "Bach" (hleb = chleb)
#   v  = w (voda = woda)                        z  = weiches s wie in "Sonne" (zima)
#   s  = scharfes s (sok)                       r  kann allein eine Silbe sein: prst, crn, trg
#   Serbisch wird auch kyrillisch geschrieben (Ћирилица) – hier steht die lateinische Schrift.
#   Bei Verben steht vorne: Infinitiv – ich-Form
