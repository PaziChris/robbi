# AUSSPRACHE (Italienisch spricht man fast so, wie man es schreibt):
#   c vor e/i  = tsch (ciao = tschao, cena = tschena)     c sonst = k (casa)
#   ch         = k (che = ke, chiave = kjawe)
#   g vor e/i  = dsch (gelato = dschelato)                g sonst = g (gatto)
#   gh         = g (spaghetti)
#   gn         = nj (bagno = banjo)                       gli = lj (famiglia = familja)
#   sc vor e/i = sch (pesce = pesche)                     sch = sk (schiena = skjena)
#   z          = ts oder ds (pizza = pitsa, zero = dsero)
#   v          = w (vino = wino)                          h  = stumm (ho = o)
#   qu         = kw (quanto = kwanto)
#   Doppelkonsonanten länger sprechen: pala (Schaufel) ≠ palla (Ball)
#   Akzent auf dem letzten Buchstaben (à è ì ò ù) = dort betonen: città, perché
#   Bei Verben steht vorne: Infinitiv – ich-Form
