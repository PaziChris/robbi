# Farsi – Vokabeln in UMGANGSSPRACHE (so wie man in Teheran spricht)
#
# Alles hier ist gesprochenes Farsi. Wo die Schrift-/Buchsprache anders ist,
# steht sie als Notiz dabei ("Buch: ...").
#
# FORMAT:   persisch (lateinisch) ; deutsch ; optionale Notiz
# Neue Kategorie einfach mit [Name] beginnen. Zeilen mit # werden ignoriert.
#
# AUSSPRACHE:
#   ā  = langes, dunkles a (zwischen a und o, wie engl. "ball")
#   a  = kurzes, helles a (fast wie ä)
#   e  = kurzes e        o = kurzes o        u = langes u      i = langes i
#   kh = wie "ch" in "Bach"      gh = Rachen-r (wie franz. r)
#   sh = sch                      ch = tsch
#   j  = dsch (wie "Job")         zh = wie "j" in "Journal"
#   y  = j (wie "ja")             z  = weiches s (wie "Sonne")
#   s  = scharfes s               '  = kurzer Stimmabsatz
#   Bei Verben steht vorne: Infinitiv – ich-Form
